How to run and use the application

You need to check out the application and build it with the help of Java and Maven.

$ ./mvnw
Project is being built.
$ java -jar target/mailclena-0.0.1-SNAPSHOT-executable.jar
22:58:33.294 [main] INFO  de.aikiit.mailclena.MailClena - Hello World :-)

Init the Maven wrapper via:

mvn wrapper:wrapper

Command line parameters

-usage: MailClena
- -c,--command <arg>    Command to execute - example: list or clean, default is list.
- -h,--host <arg>       Hostname - example: https://imap.yourisp.org
- -p,--password <arg>   Password - example: myfancypassword
- -u,--username <arg>   Username - example: myuser@tld.org

Project webpage

A Maven-generated site report is also available via this page. The site includes this README under Documentation → README. During ./mvnw site, the root README.md is copied into the generated site sources and rendered as target/site/README.html; no separate documentation copy needs to be maintained.

Software Bill of Materials

CycloneDX generates an SBOM in XML and JSON during ./mvnw package and ./mvnw site, excluding test-scoped dependencies. The files are written to target/bom.xml and target/bom.json. The site build publishes both under Documentation → Software Bill of Materials with download links on the SBOM page.
